# SYSU 抢课助手 · 新手教程

本教程按“完全不会用命令行”的新手来写。整个流程大约 5 分钟。

## 1. 一键安装

双击项目里的 `install.bat`。

安装脚本会：

- 把程序复制到当前用户的 `Programs` 目录
- 写入 Windows 开机自启
- 在开始菜单和桌面创建入口
- 自动打开控制台页面

如果电脑还没有 Python，安装脚本会尝试通过 winget 安装 Python 3.12，然后继续。

## 2. 登录教务

安装完成后会自动打开：

```text
http://127.0.0.1:8124
```

点击右上角“登录设置”，再点击“用浏览器登录”。

程序会打开一个 Edge 专用窗口。在里面登录一次中山大学教务系统。登录成功后：

- 窗口会自动关闭
- 页面右上角显示“已登录”
- 选课阶段、是否开放选课会同步显示

不需要安装浏览器扩展，也不需要复制粘贴 Cookie。

## 3. 搜索课程

在侧边栏点“搜索课程”。

输入框支持：

- 课程号，例如 `MA111`
- 课程名，例如 `英语`
- 教师姓名，例如 `王远世`

输入后会自动搜索，也可以点“搜索”按钮手动触发。

搜索结果会显示：

- 课程号和课程名
- 教学班
- 剩余名额
- 教师
- 上课时间和地点

## 4. 加入抢课目标

看到想抢的课后，有两种方式：

### 立即加入

点“加入抢课目标”，程序会把它放进“抢课目标”列表，并自动跳到该页面。

### 定时加入

点“定时”，选择开抢时间。时间一到，程序会自动开始抢。

## 5. 查看和启动

在“抢课目标”页面：

- 点播放图标立即开始抢课
- 点闪电图标只试一次
- 点时钟图标单独设置定时启动
- 点“全部定时启动”给所有待启动目标设置同一个时间
- 点停止图标暂停

每一行都会显示：

- 当前状态
- 尝试次数
- 最近一次结果

抢课成功后状态会变成“已成功”。

## 6. 已选课程

侧边栏“已选课程”会直接读取教务系统里已经选上的课，并显示：

- 课程类别，例如公必、专必、公选
- 学分
- 教学班
- 上课时间和地点
- 各类课程数量汇总

## 常见问题

### 页面一直显示“等待登录”

重新点“登录设置”→“用浏览器登录”，确认在 Edge 窗口里完成了教务登录。

### 打开页面报错

确认地址是 `http://127.0.0.1:8124`，不要多打 `s` 或改端口。

### 服务没有自动启动

重新运行 `install.bat`。它会修复开机自启。

### 提示黑名单

教务系统会检测高频抢课。出现黑名单提示时，程序会立即停止全部任务。请不要再调低请求间隔，也不要同时开多个抢课实例。

### 课程一直搜不到

可能当前选课阶段还没有开放该类课程，或者剩余名额为 0。可以先加入目标并设置“定时”，到开抢时间再试。

## 安全提醒

- Cookie 只保存在当前用户的本地应用数据目录
- 服务默认只监听本机 `127.0.0.1`
- 抢课接口只操作你自己的账号
- 请勿把自己的 Cookie 发给别人，也不要随意运行陌生人给的脚本
